
#  Bike Sales Analysis Dashboard

**An interactive data analytics project built with Microsoft Excel.**

---

##  Project Overview

This project explores customer demographics and purchasing behaviour to identify patterns associated with bike purchases. An interactive dashboard was developed using Microsoft Excel to present the analysis in a clear and accessible format.

##  Project Objectives

- Analyze customer bike purchasing behaviour.
- Explore purchasing patterns across different customer demographics.
- Examine the relationship between income, age, commute distance, and bike purchases.
- Build an interactive dashboard for data exploration and visualization.

##  Tools & Techniques

- **Microsoft Excel**
- Data cleaning and preparation
- PivotTables and PivotCharts
- Interactive slicers
- Dashboard design and data visualization

##  Dashboard Analysis

### 1. Income Analysis
Examines average customer income by gender and bike purchase status.

### 2. Age Bracket Analysis
Explores bike purchasing patterns across different customer age groups.

### 3. Commute Distance Analysis
Examines customer commute distances in relation to bike purchases.
